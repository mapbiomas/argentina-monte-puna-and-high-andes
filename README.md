# Argentina - Monte, Puna and High Andes

Developed by the team of **MapBiomas Argentina**.

## About

This repository contains scripts for classifying and filtering the **Monte, Puna and High Andes** region in Argentina.

We highly recommend reading the [Argentina Algorithm Theoretical Basis Document (ATBD)](https://argentina.mapbiomas.org/atbd-entienda-cada-etapa/). This document provides fundamental information about the classification methodology and each processing step.
