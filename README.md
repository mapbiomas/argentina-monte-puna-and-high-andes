# Argentina - Monte, Puna and High Andes

Developed by the team of **MapBiomas Argentina**.

## About

This repository contains scripts for classifying and filtering the **Monte, Puna and High Andes** region in Argentina.

We highly recommend reading the [Monte, Puna and High Andes Algorithm Theoretical Basis Document (ATBD)](https://argentina.mapbiomas.org/wp-content/uploads/sites/12/2024/05/ATDB-MapBiomas-MontePunaAltosAndes-Coll-1.pdf). This document provides fundamental information about the classification methodology and each processing step.
